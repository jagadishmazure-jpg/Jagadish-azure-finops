# `data/`

Synthetic inputs for Larkspur Freight (fictional), generated by `scripts/generate_data.py` and checked in. `python scripts/generate_data.py --check` verifies them.

| File | What it does |
|---|---|
| [`ai/`](ai/) | AI request log, agent and tenant budgets, use-case value assumptions |
| [`allocation/`](allocation/) | Tag and allocation rules, budgets per cost center |
| [`batch/`](batch/) | Batch job register for the Spot pattern |
| [`case-study/`](case-study/) | Anonymized inventory for the case study |
| [`focus/`](focus/) | FOCUS-format cost export |
| [`inventory/`](inventory/) | Resource inventory (Resource Graph shape) |
| [`licenses/`](licenses/) | Licence register for Hybrid Benefit |
| [`metrics/`](metrics/) | Utilization, traffic and compute usage |
| [`network/`](network/) | Endpoints and cross-region copies |
| [`pricing/`](pricing/) | Retail Prices list-price snapshot |
| [`storage/`](storage/) | Blob containers by age bucket |
